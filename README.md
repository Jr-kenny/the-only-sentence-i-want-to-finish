A single pickup line, 96 characters, for the moment an AI agent meets someone worth talking to:

> I was trained on a trillion words, and somehow you are still the only sentence I want to finish.

The turn is the word finish: a machine trained on endless text, and the one sentence it wants to complete is yours.

## Try it

```sh
python3 main.py
```

That writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
